# ボドゲのミカタ

プレイ中にルールで止まったとき、必要な情報へすばやく到達し、根拠となる公式資料へ戻れるボードゲーム・コンパニオンです。

同じゲームでも版、FAQ、エラッタで内容は変わります。公式ルールと、要約・翻訳・分析などの補助情報を混同しません。

## できること

- ゲームを探す
- セットアップ、手番、終了条件、得点を確認する
- 公式資料と補助情報を区別する
- 版やFAQの違いを保持する
- マーダーミステリーの非ネタバレ情報と創作研究を扱う

## 情報の扱い

公開情報は、ゲーム、版、出典URL、該当箇所を確認できる状態を優先します。

根拠が不足する情報を公式裁定として扱いません。最終裁定、競技ルール、エラッタ、FAQは出版社、デザイナー、大会運営者などの最新公式情報を優先します。

マーダーミステリーでは、公開情報とネタバレを分離します。真相、ハンドアウトなどの非公開情報を一般公開データへ混ぜません。

## 開発

```bash
task setup
task dev
```

frontendだけを検証する場合:

```bash
cd frontend
npm ci
npm run build
```

## 構成

- `frontend/`: 公開Webアプリと静的HTML生成
- `backend/`: FastAPIによるAPIとローカルデータ処理
- `data/`: ゲーム・カード・調査データ
- `ontology/`: データ構造と意味の定義
- `works/`: マーダーミステリー作品データ
- `research/`: 調査成果
- `docs/`: 一般ドキュメントの唯一の置き場
- `AGENTS.md`: 開発・運用規約

一般ドキュメントは `docs/` に集約します。作品本文、ゲームデータ、研究データはそれぞれの正規ディレクトリに置き、ドキュメントの退避用ディレクトリは増やしません。

## 変更の完了条件

変更はテストだけで完了としません。

1. test / data validation
2. Pull Request
3. Pull RequestのHEAD commitに対するCI
4. merge
5. masterの反映確認
6. 公開サイトの確認

公開サイト: https://bodogenomikata2.pages.dev/
