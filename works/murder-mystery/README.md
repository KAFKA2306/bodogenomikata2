# オリジナル・マーダーミステリー制作ワークスペース

このディレクトリは、既存作品の調査・評価データではなく、**人間が発案し、人間が最終判断する新作**を管理する場所です。

`data/`は外部作品の観測、`research/`は横断調査、`ontology/`は概念定義、`works/`は自作の制作物という責務分離を守ります。

## ステージ

```text
works/murder-mystery/
├── 00-inbox/        # 人間が書いた原初の着想。選別前
├── 10-incubating/   # 主題・矛盾・体験の核を掘る
├── 20-developing/   # 人物、起承転結、謎、感情設計を接続
├── 30-playtesting/  # 実プレイで検証し、仮説と結果を分離
├── 40-production/   # 頒布可能な版、素材、運用へ固定
├── 90-archived/     # 破棄、凍結、統合済み。理由を残す
└── _templates/      # 新規作品を起票する正準テンプレート
```

作品は一つのステージにだけ存在させます。コピーで段階を増やさず、ディレクトリを移動し、`project.yaml`の`status`を更新します。

## 作品ディレクトリ

```text
{stage}/{slug}/
├── project.yaml                   # ID、状態、作者、制作来歴、公開可否
├── public/README.md               # ネタバレなしの企画説明
├── design/
│   ├── 00-human-seed.md           # 人間が最初に書いた観察・執着・問い
│   ├── 10-creative-thesis.md      # 何を体験させ、何を安易に救済しないか
│   ├── 20-characters.yaml         # 欲求、矛盾、依存、誤認
│   ├── 30-plot-beats.yaml         # 起承転結と認識変化
│   ├── 40-mystery-and-experience.yaml
│   └── 50-originality-audit.md
├── playtest/                      # セッション記録と観測
├── revisions/CHANGELOG.md         # 変更理由。結果だけでなく棄却理由も残す
└── private/                       # 真相、秘密、HO、結末。Git追跡禁止
```

## 人間主体の制作規則

AI利用の有無を文章から推定することはしません。代わりに、制作工程を明示します。

人間が必ず決めるもの:

- 原初の観察、違和感、恐れ、執着
- 作品が扱う倫理的矛盾
- 各人物の欲求、自己欺瞞、傷つけ方
- 真相と驚きの因果
- 終盤でプレイヤーに負わせる選択
- 感情的頂点、結末、最終文章、台詞

AIを補助に限定できるもの:

- ファイル整理、表記統一、構造化
- 矛盾候補・未回収要素の指摘
- 公開情報の調査補助と出典整理
- プレイテスト記録の要約
- 複数案の比較表やチェックリスト

AIへ委ねないもの:

- 正準プロットの生成
- 登場人物の人生・秘密・台詞の代筆
- どんでん返し、感情的頂点、結末の決定
- 人間の経験らしさを装う架空ディテールの量産

`00-human-seed.md`はAIへ入力する前に人間が記入します。空欄のまま次のステージへ進めません。

## 秘密情報

このリポジトリが公開されている限り、真相、犯人、秘密、ハンドアウト本文、結末詳細をcommitしてはいけません。各作品の`private/`は`.gitignore`で除外します。

秘密本文を版管理する場合は、アクセス制御されたprivate repositoryまたは暗号化ストレージを使用し、`project.yaml`には参照IDだけを置きます。

## 新規作品の起票

```bash
task work:new -- my-human-slug "仮タイトル"
```

既定では`00-inbox/`へ作成されます。

```bash
task work:new -- my-human-slug "仮タイトル" 10-incubating
```

構造検証:

```bash
task work:validate
```
