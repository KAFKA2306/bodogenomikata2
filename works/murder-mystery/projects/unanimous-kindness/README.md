# 満場一致で、あなたをやめる

> あなたを守るため、私たちはあなたの人生を六つの臓器に分けた。

## 公開用概要

八年前、心身を崩した劇作家・御影灯里を救うため、六人の仲間は彼女の人生を分担した。

- 胃袋――金銭、食事、住居
- 肺――医療、睡眠、身体
- 心臓――恋愛、親密さ、私信
- 両手――仕事、創作、契約
- 口――発言、評判、公開人格
- 脳――重大な決定と全体調整

三週間だけの予定だった「代理」は八年続き、灯里の名前で発表される作品や言葉まで、仲間たちが共同で作るようになった。

取り壊し前夜の旧劇場。六人を集めた調整役・守屋巴は、灯里の人生を返す「身体返還式」を始める。しかし巴は、六つの鍵が同時に揃わなければ開かない古い舞台装置――**満場一致棺**の中で死亡する。

犯人を探すほど、六人は理解する。

灯里の判断は分担できた。責任も分担できた。  
しかし、結果として残る痛みだけは、誰も引き受けていなかった。

## 想定仕様

- 六人の善意で一人を作る、関係性マーダーミステリー
- 6人＋GM 1人
- 180分前後
- 推理：中／関係性：高／ロールプレイ：高
- 固有メカニクス：六臓器の代理権、善意の拒否権、身体返還式、因果組立投票
- 注意事項：精神的不調、共依存、過干渉、本人同意の侵害、服薬への介入、閉所、事故死、友人関係の破綻

## 制作状態

Prototype 0.3。プレイテスト前です。

作品の原点は作者本人が提示した「友人や仲間の善意が自分を縛った」という実感です。詳細な事件構造、役別情報、証拠、台詞、結末はAI支援によるプレイテスト素材であり、人間作の正準版・販売版とは扱いません。
