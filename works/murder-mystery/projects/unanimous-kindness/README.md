# 満場一致で、あなたをやめる

> 助けられない日は、誰かがあなたになる。

八年前、心身を崩した劇作家・御影灯里を救うため、六人の仲間はグループチャット「今日の灯里」を作った。

当番になった人は、その日だけ灯里として生きる。

- 母親へ電話する
- 取引先へ謝る
- 家賃を払う
- 未読メールを返す
- 通院予定を決める
- 原稿を提出する
- SNSへ「元気です」と投稿する

三週間だけの予定だった。しかし灯里が回復した後も、周囲は本人より、失敗せず、返信が早く、いつも感謝する“代行された灯里”を信用した。

取り壊し前夜の旧アパート。制度を作った守屋巴は、八年分の「本人ノート」と全アカウントを返す会を開く。

その夜、巴が裏階段で死亡する。

全員のスマートフォンには、巴から同じ短文が届いていた。

> たすけて

しかしグループチャットでは、すでに「対応済み」のチェックが付いていた。

- 6人＋GM
- 170〜190分
- 関係性マーダーミステリー／生活代行サスペンス
- 固有要素：本人ノート、今日の灯里当番、既読盤、代理停止、予約感謝メッセージ
- 注意事項：精神的不調、共依存、本人同意の侵害、なりすまし、金銭管理、事故死、友人関係の破綻
