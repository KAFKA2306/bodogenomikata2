# 満場一致で、あなたをやめる

> あなたを守るため、私たちはあなたの人生を六つに分けた。

## 公開用概要

八年前、心身を崩した友人・灯里を救うため、六人の仲間は彼女の生活を分担した。

連絡、金銭、仕事、家族、恋愛、創作、そして重大な判断。最初は数週間だけの約束だった。しかし善意の代理は生活の制度となり、灯里の人生は「仲間全員の同意がなければ変更できないもの」へ変わっていった。

取り壊し前夜の旧劇場に、七人は再び集められる。灯里は宣言する。

> 今夜、私を全部返して。

その直後、この仕組みを作った人物が、舞台上で死亡する。

犯人を探すほど、六人は自分が灯里を救ったのか、所有したのか分からなくなっていく。

## 想定仕様

- ジャンル：関係性マーダーミステリー／心理劇
- 人数：6人＋GM 1人
- 時間：150〜180分
- 舞台：閉鎖される旧劇場
- 中核体験：善意による拒否権、共同責任、本人の選択を許せるか
- 注意事項：精神的不調、過干渉、服薬への介入、共依存、事故死、友人関係の破綻

## 制作状態
